Overview

OPERA-DSP is an open-source FMCW radar DSP hardware library. It provides essential IP cores for radar signal processing, including windowing functions, FFT, magnitude computation, and CFAR detection — all built with Chisel.

Language breakdown: Scala 96.9% · Makefile 2.7% · Verilog 0.4%

Each block supports both AXI4 and TileLink interfaces and can be used standalone or integrated into a larger SoC design. Generated SystemVerilog output is placed in the ./rtl directory.

Dependencies

OpenJDK & SBT

OPERA-DSP is based on Chisel. You'll need SBT and OpenJDK installed:

# Install OpenJDK on Debian/Ubuntu
$ sudo apt install openjdk-17-jdk

For SBT installation, follow the official SBT guide.

Git

$ sudo apt install git

OSS CAD Suite

To run tests, you'll need open-source tools like Verilator. The easiest way to install them is via the OSS CAD Suite from YosysHQ. Download the release for your system and add it to your PATH.

Sphinx (for documentation)

# Install Sphinx and the RTD theme
$ pip install sphinx sphinx_rtd_theme

# For PDF output, install TeX Live
$ sudo apt install texlive-base texlive-latex-recommended \
    texlive-latex-extra texlive-fonts-recommended

Standalone Setup

When using OPERA-DSP as a standalone project, clone the required submodules. These include rocket-chip, dsptools, and rocket-dsp-utils: 

# From the project root
$ make clone_dependencies

This clones all submodules into the ./dependencies folder.

PreProcessing Block

The PreProcessing block formats raw ADC data from the FMCW radar sensor, ensuring compatibility with subsequent DSP blocks.

→ Full PreProcessing Documentation

RTL Generation

# AXI4 variant
$ make rtl_preprocessing_axi4

# TileLink variant
$ make rtl_preprocessing_tl

Generated SystemVerilog will be in ./rtl.

Tests

$ make test_preprocessing

By default, 4,884 tests will run (approximately 2 hours). Results go to ./test_run_dir. To reduce the number of tests, modify parameters in PreProcessingSpec.scala.

Windowing Block

A windowing function applied before FFT to reduce spectral leakage in the frequency spectrum.

→ Full Windowing Documentation

RTL Generation

# AXI4
$ make rtl_windowing_axi4

# TileLink
$ make rtl_windowing_tl

Tests

# AXI4 only
$ make test_windowing_axi4

# TileLink only
$ make test_windowing_tl

# Both variants
$ make test_windowing_all

672 tests per variant, ~30 minutes each. Modify WindowingAXI4Spec.scala or WindowingTLSpec.scala to adjust.

Magnitude Block

Computes the magnitude (or approximation) of a complex signal. Supports squared magnitude, JPL magnitude approximation, and log2 computation for real input signals.

→ Full Magnitude Documentation

RTL Generation

# AXI4
$ make rtl_magnitude_axi4

# TileLink
$ make rtl_magnitude_tl

Tests

# AXI4
$ make test_magnitude_axi4

# TileLink
$ make test_magnitude_tl

# All (takes a long time)
$ make test_magnitude_all

1,368 tests per variant, ~60 minutes each. Results in ./log-magnitude/test_run_dir.

Building Documentation

Each block has its own Sphinx documentation. The generated HTML is output into ./website/docs/ so it's served alongside this site. You can also generate PDF output: 

# PreProcessing docs
$ make docs_preprocessing_html   # → ./website/docs/preprocessing/
$ make docs_preprocessing_pdf

# Windowing docs
$ make docs_windowing_html       # → ./website/docs/windowing/
$ make docs_windowing_pdf

# Magnitude docs
$ make docs_magnitude_html       # → ./website/docs/log-magnitude/
$ make docs_magnitude_pdf

Once generated, the Sphinx docs are accessible from the sidebar links or directly at docs/<block>/index.html.
