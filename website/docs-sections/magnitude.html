Magnitude Block

Computes the magnitude (or approximation) of a complex signal. Supports squared magnitude, JPL magnitude approximation, and log2 computation for real input signals.

→ Full Magnitude Documentation

RTL Generation

# AXI4
$ make rtl_magnitude_axi4

# TileLink
$ make rtl_magnitude_tl

Tests

# AXI4
$ make test_magnitude_axi4

# TileLink
$ make test_magnitude_tl

# All (takes a long time)
$ make test_magnitude_all
