PreProcessing Block

The PreProcessing block formats raw ADC data from the FMCW radar sensor, ensuring compatibility with subsequent DSP blocks.

→ Full PreProcessing Documentation

RTL Generation

# AXI4 variant
$ make rtl_preprocessing_axi4

# TileLink variant
$ make rtl_preprocessing_tl

Generated SystemVerilog will be in ./rtl.

Tests

$ make test_preprocessing

By default, 4,884 tests will run (approximately 2 hours). Results go to ./test_run_dir. To reduce the number of tests, modify parameters in PreProcessingSpec.scala.
