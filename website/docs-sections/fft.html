FFT Block

The FFT block implements a streaming single-path delay-feedback FFT with Radix-2 and Radix-22 cores, optional runtime configuration, bit reversal, and AXI4 or TileLink memory-mapped wrappers.

→ Full FFT Documentation

RTL Generation

# AXI4
$ make rtl_fft_axi4

# TileLink
$ make rtl_fft_tl

# All variants
$ make rtl_fft_all

Tests

# AXI4
$ make test_fft_axi4

# TileLink
$ make test_fft_tl

# Full FFT suite
$ make test_fft_all

The full suite covers memory-mapped wrappers, bit reversal, SDF stages, FFT models, hardware/model comparisons, floating-point comparisons, and SQNR.
