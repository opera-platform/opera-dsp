CFAR Block

The CFAR block implements 1D Constant False Alarm Rate target detection for range spectra. It supports Cell-Averaging and Generalized Ordered-Statistic CFAR modes, configurable guard/reference windows, edge policies, peak grouping, and AXI4 or TileLink memory-mapped wrappers.

→ Full CFAR Documentation

RTL Generation

# AXI4
$ make rtl_cfar_axi4

# TileLink
$ make rtl_cfar_tl

# Both variants
$ make rtl_cfar_all

Tests

# Memory-mapped wrappers
$ make test_cfar_axi4
$ make test_cfar_tl

# Full CFAR suite
$ make test_cfar_all

The full suite covers direct CFAR behavior, CA/GOS families, delay cells, memory-mapped AXI4 and TileLink wrappers, window providers, rank providers, and linear insertion sorter implementations.
